# Bajrang · बजरंग

रोज़ एक मिनट की हनुमान पूजा। एक टैप में पूजा पूरी, और लगातार साधना का हल्का सा अनुशासन —
बिना डाँटे, बिना लालच के।

A mobile-first devotional app for a daily 1-minute Hanuman ritual. Warm, calm, Hindi-first,
designed to feel like a temple app rather than a game.

## चलाने का तरीका · Run

```bash
npm install
npm run dev      # लोकल डेवलपमेंट
npm run build    # प्रोडक्शन बिल्ड (+ PWA service worker)
npm run preview  # बिल्ड को देखिए
```

फ़ोन पर देखने के लिए: `npm run dev -- --host` चलाके उसी Wi-Fi पर फ़ोन से IP खोलिए।

## तकनीकी · Tech

- React 19 + TypeScript + Vite 7
- Tailwind CSS v4 (`@theme` में केसरिया/गहरा लाल/क्रीम/सोना रंग)
- PWA — `vite-plugin-pwa`, फ़ोन पर इंस्टॉल होने योग्य, ऑफ़लाइन चलता है
- कोई सर्वर नहीं, कोई लॉगिन नहीं — सब कुछ `localStorage` में
- बिना किसी बाहरी लाइब्रेरी/ऑडियो फ़ाइल के:
  - `src/lib/audio.ts` — मंदिर की घंटी, और "ॐ" drone दोनों Web Audio से बने हैं
  - `src/lib/shareCard.ts` — साझा करने वाला कार्ड सीधे canvas पर बनता है (हनुमान जी की सिंहावली सहित)

## अनुभव (UX) · क्या ख़ास है

- **पूजा के दौरान स्क्रीन जली रहती है** — Wake Lock API (`src/lib/device.ts`), 60 सेकंड में
  स्क्रीन बुझने से परेशान नहीं होना पड़ता; टैब लौटने पर अपने आप फिर जग जाती है
- **साँस का घेरा** — प्रगति घेरे के पीछे 7 सेकंड का धीमा pulse, ताकि मन शांत हो
- **हल्का कंपन** — पूजा पूरी होते ही `navigator.vibrate([14,60,24])`
- **टैब की जगह याद रहती है** — वापस लौटने पर स्क्रॉल वहीं से शुरू; उसी टैब पर दोबारा
  दबाने पर ऊपर चला जाता है
- **समय के हिसाब से नमस्कार** — शुभ प्रभात / नमस्कार / शुभ संध्या / शुभ रात्रि
- **नए उपयोगकर्ता को "० दिन" नहीं** — "नया शुरुआत 🪔" दिखता है (यह उम्मीद का ऐप है)
- **याद दिलाने की नम्र सलाह** — 3 दिन के बाद, सिर्फ़ एक बार, और "बाद में" छूट भी दिया जा सकता है
- **Install banner** — Chromium पर "लगाएँ" बटन, iOS पर Safari के निर्देश
- **बड़े अक्षर वाली जगह** — हर बटन/टॉगल कम से कम 56–58px, devanagari line-height 1.6–1.9,
  `prefers-reduced-motion` का पूरा समर्थन

## आवाज़ · Audio

| क्या | कैसे |
| --- | --- |
| घंटी | पूजा पूरी होने पर — 4 आंशिक (partial) के साथ, पुराने version से लगभग आधी धीमी |
| मंत्र | पूजा के दौरान 3 हार्मोनिक (C3/G3/C4) + 0.18Hz LFO — साँस जैसा बहुत हल्का drone |
| बंद करना | पूजा स्क्रीन पर 🔊 बटन, या सेटिंग → "पूजा की आवाज़" |

हर आवाज़ user gesture के बाद ही चलती है (ब्राउज़र की नीति), इसलिए मंत्र तभी शुरू होता है
जब आप "आज की पूजा शुरू करें" दबाते हैं। पूजा पूरी होते ही मंत्र पहले 1.2 सेकंड में धीमा
होता है, ताकि घंटी साफ़ सुनाई दे।

## साझा करने वाला कार्ड · Share card

- 1080 × 1080 PNG, लगभग 1 MB — canvas से सीधे बनता है
- केसरिया ढाल (gradient), हनुमान जी की सिंहावली (मुकुट, प्रभामंडल, गदा, पूँछ, जोड़े हाथ), सामने दीवा
- नाम और स्ट्रीक `800` weight में मोटे अक्षर; लंबा नाम/बड़ी गिनती आ जाए तो अक्षर अपने आप छोटे होते हैं
- भेजने के तीन तरीके:
  1. **साझा करें** — Web Share Level 2, तस्वीर साफ़ फ़ाइल के रूप में (Android/iOS WhatsApp सीधे)
  2. **WhatsApp पर भेजें** — तस्वीर सहेजकर `wa.me` खोलता है
  3. **तस्वीर सहेजें / खोलें** — Blob URL से download; iOS Safari के लिए "खोलें" (Save Image)

## याद दिलाना · Reminder

संदेश: `🙏 [नाम], हनुमान जी का वार है — आज की पूजा 1 मिनट में पूरी करो`

`src/lib/reminder.ts` तीन तरीके आज़माता है:

1. App खुला हो तो `setTimeout` से समय पर (service worker के ज़रिए दिखाता है)
2. App बंद होकर खुले और समय बीत चुका हो तो एक बार "पछड़ा हुआ" संदेश
3. Chrome समर्थन दे तो Periodic Background Sync से registration

सेटिंग में संदेश का नमूना और "अभी संदेश भेजकर देखें" बटन भी है।
**सच्चाई:** ब्राउज़र बंद होने पर JS नहीं चलता, इसलिए सबसे भरोसेमंद तरीका फ़ोन की अलार्म है —
यही सेटिंग में लिखा है।

## स्ट्रीक तर्क · Streak logic

`src/lib/store.ts` में — तारीखें हमेशा स्थानीय समय के `YYYY-MM-DD` रूप में (UTC नहीं):

- आज पूजा हो चुकी है और आखिरी पूजा **कल** थी → `streak + 1`
- एक या ज़्यादा दिन छूट गए → `streak = 1` (नया सिलसिला)
- आज पहले ही पूजा हो चुकी हो → गिनती दोबारा नहीं होती
- दिन छूटने पर कोई डाँट नहीं: होम पर "चिंता मत करो, फिर से शुरू करो 🙏"

## याद दिलाना (पुराना नोट)

ऊपर वाला हिस्सा अब असली कार्यान्वयन है; ब्राउज़र बंद होने पर Notification नहीं चल पाता,
इसलिए फ़ोन की अलार्म का सुझाव सेटिंग में दिया गया है।

## त्योहार की तिथि · Festival dates

हनुमान जयंती और राम नवमी चाँद के हिसाब से बदलती हैं। ऐप में अनुमानित तिथि दी गई है और
"अनुमानित" का निशान लगा है — पंचांग के अनुसार पंचांग टैब से ठीक कर लीजिए।
मंगलवार और शनिवार की संकष्टी हमेशा सही होती है, इसलिए वे गिनती में दिखती हैं।
